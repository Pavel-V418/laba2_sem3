Макрос	        Условие	            Что проверяет	Пример ситуации
EXPECT_EQ(a, b) / ASSERT_EQ	a == b	Равенство	Результат функции равен ожидаемому значению.
EXPECT_NE(a, b) / ASSERT_NE	a != b	Неравенство	Убедиться, что ID разные, статус не равен ошибке (-1), получен новый объект.
EXPECT_LT(a, b) / ASSERT_LT	a < b	Строго меньше	Индекс меньше размера контейнера, задержка меньше лимита.
EXPECT_LE(a, b) / ASSERT_LE	a <= b	Меньше или равно	Значение не превышает порог, время укладывается в бюджет.
EXPECT_GT(a, b) / ASSERT_GT	a > b	Строго больше	Размер больше нуля, значение выше минимального порога.
EXPECT_GE(a, b) / ASSERT_GE	a >= b	Больше или равно	Размер не меньше минимального, значение не ниже допустимого уровня.

INSTANTIATE_TEST_SUITE_P - это макрос Google Test для параметризованных тестов: он говорит фреймворку «запусти эти тесты для каждого из заданных наборов данных».
